  config.py: Change N_SPLITS, OPTUNA_TRIALS

MEMORY OPTIMIZATION:
  config.py: Reduce CHUNK_SIZE
  preprocess.py: Enable sample=True


⚠️ COMMON ISSUES & SOLUTIONS
════════════════════════════════════════════════════════════════════════════════

Out of Memory
  Solution: Reduce CHUNK_SIZE in config.py
  Alternative: Use sample=True in preprocess()

CSV Files Not Found
  Solution: Ensure files in data/ folder
  Check: CSV file names match *.csv pattern

Column Name Errors
  Solution: Verify CSV columns: date, open, high, low, close, volume
  Note: Case-insensitive, auto-standardized

Slow Training
  Solution: Reduce OPTUNA_TRIALS
  Alternative: Reduce N_SPLITS

Installation Issues
  Solution: pip install --upgrade pip
  Then: pip install -r requirements.txt
