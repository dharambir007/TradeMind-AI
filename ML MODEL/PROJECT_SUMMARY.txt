CONFIGURATION OPTIONS
════════════════════════════════════════════════════════════════════════════════

ADJUSTABLE IN config.py:

Data:
• DATA_FOLDER: Path to CSV files
• CSV_PATTERN: File matching pattern
• CHUNK_SIZE: Memory optimization

Features:
• LAG_FEATURES: [1, 2, 3, 5]
• MA_PERIODS: [10, 50]
• RSI_PERIOD: 14
• MACD parameters: FAST=12, SLOW=26, SIGNAL=9

Model:
• MODEL_TYPE: "lgb" or "xgb"
• OPTUNA_TRIALS: 50 (hyperparameter tuning iterations)
• N_SPLITS: 5 (cross-validation folds)
• TEST_SIZE: 0.2 (train-test split ratio)

Hyperparameter ranges:
• num_leaves: 20-100
• max_depth: 3-15
• learning_rate: 0.01-0.2
• regularization (L1/L2): 0-5
