FEATURE ENGINEERING PIPELINE (87 Total Features)
═══════════════════════════════════════════════════════════════════════════════

INPUT: OHLCV Data
  └── Open, High, Low, Close, Volume, Date

PROCESSING:

Stage 1: PRICE FEATURES (8)
  ├─ hl_ratio       = High / Low
  ├─ co_ratio       = Close / Open
  ├─ oc_ratio       = Open / Close
  ├─ hc_ratio       = High / Close
  ├─ lc_ratio       = Low / Close
  ├─ range          = High - Low
  ├─ range_pct      = (High - Low) / Close * 100
  └─ avg_price      = (O + H + L + C) / 4

Stage 2: VOLUME FEATURES (3)
  ├─ volume_ma_ratio    = Volume / MA(Volume, 20)
  ├─ volume_change      = pct_change(Volume)
  └─ log_volume         = log(Volume + 1)

Stage 3: TECHNICAL INDICATORS (12)
  ├─ rsi                = Relative Strength Index (14)
  ├─ macd               = MACD (12, 26, 9)
  ├─ macd_signal        = MACD Signal line
  ├─ macd_hist          = MACD Histogram
  ├─ bb_upper           = Bollinger Band Upper
  ├─ bb_middle          = Bollinger Band Middle
  ├─ bb_lower           = Bollinger Band Lower
  ├─ bb_pct             = (Close - Lower) / (Upper - Lower)
  ├─ atr                = Average True Range (14)
  └─ MA_10, MA_50       = Moving Averages

Stage 4: RETURNS (6)
  ├─ return_1, 5, 10    = Daily, 5-day, 10-day returns
  └─ log_return_1, 5    = Log returns

Stage 5: VOLATILITY (2)
  ├─ volatility_10      = Rolling std(return, 10)
  └─ volatility_20      = Rolling std(return, 20)

Stage 6: LAG FEATURES (12)
  ├─ close_lag_1,2,3,5
  ├─ volume_lag_1,2,3,5
  └─ return_1_lag_1,2,3,5

Stage 7: ROLLING STATISTICS (12)
  ├─ rolling_mean_5,10,20
  ├─ rolling_std_5,10,20
  ├─ rolling_min_5,10,20
  └─ rolling_max_5,10,20

Stage 8: TARGET (1)
  └─ target_return = Next-day return

OUTPUT: 87 Features + Target
